# pdf-writer

A small PDF writer for business documents: receipts, invoices, reports and long registers. You describe the document as plain data, and it returns the PDF's bytes.

The library has no dependencies and uses only the platform, so it runs unchanged on Cloudflare Workers, Node, Bun, Deno and in browsers. Fonts are embedded and subset, and pages are laid out and written in milliseconds.

It is under construction and not yet published. The name is not final. `docs/design.md` records the decisions.
